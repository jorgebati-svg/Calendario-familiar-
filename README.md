# Focaccia Recipe Calculator

A single-page calculator for scaling focaccia dough using baker's percentages.

## Features

- **Size by flour weight** — enter a flour amount and get water, salt, olive oil, and yeast scaled to it.
- **Size by pan** — enter your pan dimensions (rectangular or round), number of pans, and desired crumb style (thin, classic, or thick), and the calculator works backward to the flour weight needed.
- Adjustable baker's percentages for hydration, salt, olive oil, and instant dry yeast, with quick presets for same-day, overnight, and cold-retard fermentation schedules.

## Usage

Open `index.html` in any browser — no build step or server required.
